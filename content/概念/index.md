# 概念索引

本页汇集《传习录》中最值得深入理解的核心概念，按四大维度分类整理，方便检索与对照阅读。

---

## 一、本体论概念（心学基础）

> 这些概念构成阳明心学的形而上学地基——世界与人心究竟是什么。

| 概念 | 一句话解释 | 详细词条 |
|------|-----------|---------|
| **心即理** | 心外无理，理不在物而在心 | [[概念/本体论/心即理]] |
| **良知** | 先天内在的道德判断力，不学而知 | [[概念/本体论/良知]] |
| **心体** | 心的本然状态：至善无恶，虚灵不昧 | [[概念/本体论/心体]] |
| **天理** | 心中先验的道德法则，与人欲相对 | [[概念/本体论/天理与人欲]] |
| **性** | 心之本体，性即理 | [[概念/本体论/性]] |
| **万物一体** | 仁者以天地万物为一体，由气相通 | [[概念/本体论/万物一体]] |

## 二、功夫论概念（实践工夫）

> 这些概念回答"怎么做"——如何通过日常工夫回归心体。

| 概念 | 一句话解释 | 详细词条 |
|------|-----------|---------|
| **知行合一** | 真知必行，真行即知，知行本体原为一 | [[概念/功夫论/知行合一]] |
| **致良知** | 将良知推广贯彻到事事物物上 | [[概念/功夫论/致良知]] |
| **格物** | 正心——正意念之不正，以归于正 | [[概念/功夫论/格物]] |
| **诚意** | 意念发动处实实落落依良知而行 | [[概念/功夫论/诚意]] |
| **立志** | 念念不忘存天理，"必为圣人之志" | [[概念/功夫论/立志]] |
| **事上磨炼** | 功夫不在静坐而在实事中历练 | [[概念/功夫论/事上磨炼]] |
| **主一** | 专主一个天理，非逐物 | [[概念/功夫论/主一]] |
| **去人欲存天理** | 功夫核心：克除私欲，回归本然 | [[概念/功夫论/去人欲存天理]] |
| **省察与存养** | 省察是有事时的存养；存养是无事时的省察 | [[概念/功夫论/省察与存养]] |
| **静坐** | 收摄精神的辅助功夫，非工夫本身 | [[概念/功夫论/静坐]] |

## 三、境界论概念（圣学境界）

> 这些概念描绘道德修养到达某种高度后的精神状态。

| 概念 | 一句话解释 | 详细词条 |
|------|-----------|---------|
| **至善** | 心体纯乎天理之极，非事物上的完美 | [[概念/境界论/至善]] |
| **圣人** | 良知无障碍、完全呈现的人格典范 | [[概念/境界论/圣人]] |
| **狂者精神** | 不执于世俗成见，直指本体，勇于担当 | [[概念/境界论/狂者精神]] |
| **不动心** | 无内外执着，顺应万物而不被牵绊 | [[概念/境界论/不动心]] |
| **乐** | 良知完全呈现时的自然愉悦状态 | [[概念/境界论/乐]] |
